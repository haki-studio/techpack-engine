# Close-ups to generate — pixel-sky-fleece

**Why:** the only source is `inputs/front.png`, an AI render about 1500 px wide (0.6 mm per pixel on the garment). At that
size the small sparkles, the bird's wing edge and the cloud checker are blurred together. The art had to be redrawn from
the blur (see J3 / G pages: "redrawn from a low-res mockup"). A sharp close-up of each panel lets us trace them exactly.
It also lets us judge thread direction against a reference, which R1 currently reports as "not judged".

**How (about 10 minutes):**
1. Open the image tool that made the mockup (ChatGPT image).
2. Attach `projects/pixel-sky-fleece/inputs/front.png`.
3. Paste one prompt below and run it. Repeat for each prompt.
4. Save each result as `closeup_<name>.png`, using the name in brackets, into
   `inbox/pixel-sky-fleece/closeups/`. The builder then traces from them.
5. Reject a result that moved, added or removed a sparkle or a cloud. Compare it with the mockup. The mockup stays the
   reference for positions and sizes.
